# Обновление логики стен

## Изменения

### 1. Разделение стен на личную и общую

**Личная стена (`/wall`):**
- Показывает только посты текущего пользователя
- Содержит форму для создания новых постов
- Отображает профиль текущего пользователя справа
- Заголовок: "Моя стена"

**Общая лента (`/feed`):**
- Показывает все посты всех пользователей
- Содержит поиск по тегам
- Отображает профиль текущего пользователя справа
- Заголовок: "Общая лента"

**Индивидуальная стена пользователя (`/user/<username>`):**
- Показывает посты конкретного пользователя
- Не содержит форму создания постов
- Отображает профиль целевого пользователя справа
- Заголовок: "Стена [username]"

### 2. Обновление навигации

- Ссылка "Стена" → "Моя стена" (ведет на `/wall`)
- Добавлена ссылка "Общая лента" (ведет на `/feed`)

### 3. Обновление поиска

- Поиск по тегам (#тег) теперь ведет на общую ленту (`/feed`)
- Поиск пользователей ведет на страницу поиска (`/search`)
- Ссылки на теги в постах ведут на общую ленту

### 4. Обновление профиля

- Вкладка "Мои публикации" ведет на личную стену (`/wall`)
- Карточки постов в профиле ведут на личную стену

## Логика работы

1. **Пользователь заходит на `/wall`** → видит только свои посты
2. **Пользователь заходит на `/feed`** → видит все посты всех пользователей
3. **Пользователь ищет кого-то** → находит в поиске и может перейти на его стену
4. **Пользователь кликает на тег** → переходит на общую ленту с фильтром по тегу
5. **Пользователь кликает на имя в посте** → переходит на стену этого пользователя

## Файлы изменены

- `backend/app.py` - добавлен маршрут `/feed`, обновлен `/wall`
- `backend/templates/wall.html` - обновлена логика отображения
- `backend/templates/base.html` - обновлена навигация и поиск
- `backend/templates/profile.html` - обновлена навигация и ссылки
