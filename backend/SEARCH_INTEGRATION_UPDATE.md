# Интеграция поиска в существующую строку поиска

## Обзор изменений

Интегрирован функционал поиска пользователей в существующую строку поиска в header, убрана дублирующая ссылка "Поиск" из навигации.

## Изменения

### 1. Убрана ссылка "Поиск" из навигации
- Удалена ссылка `<li><a href="/search">Поиск</a></li>` из header-nav
- Навигация стала более чистой и без дублирования

### 2. Обновлена существующая форма поиска в header
- **Placeholder**: Изменен на "Поиск пользователей или #тегов..."
- **ID**: Добавлены id="headerSearchForm" и id="headerSearchInput"
- **Функциональность**: Интегрирован JavaScript для обработки поиска

### 3. Добавлен JavaScript для умного поиска
- **Поиск пользователей**: Обычный текст → `/search?q=запрос`
- **Поиск по тегам**: Запрос начинается с # → `/wall?q=#тег`
- **Валидация**: Минимум 2 символа для поиска
- **Подсказки**: Динамическое изменение placeholder при ошибках
- **Автозаполнение**: Из URL параметров при загрузке страницы

### 4. Обновлена страница поиска пользователей
- **Автопоиск**: При загрузке с параметром q автоматически выполняется поиск
- **Подсказка**: Добавлена информация о поиске по тегам
- **Описание**: Улучшено описание функциональности

## Функциональность

### Умный поиск
```
Поиск пользователей: "Иван Петров" → /search?q=Иван%20Петров
Поиск по тегам: "#наука" → /wall?q=%23наука
```

### Валидация
- Минимум 2 символа для поиска
- Подсказки при коротких запросах
- Автоматическое восстановление placeholder

### UX улучшения
- Единая точка входа для всех типов поиска
- Автозаполнение из URL параметров
- Плавные переходы между страницами
- Понятные подсказки и описания

## Преимущества

1. **Единообразие**: Одна строка поиска для всех типов поиска
2. **Удобство**: Не нужно переключаться между разными формами
3. **Интуитивность**: # для тегов, обычный текст для пользователей
4. **Чистота**: Убрано дублирование в навигации
5. **Гибкость**: Легко добавить новые типы поиска

## Тестирование

Для тестирования:
1. Откройте http://localhost:5000
2. Введите имя пользователя в строку поиска → должен открыться поиск пользователей
3. Введите #тег в строку поиска → должна открыться стена с поиском по тегам
4. Введите короткий запрос → должна появиться подсказка
5. Перейдите на /search?q=test → должен автоматически выполниться поиск
