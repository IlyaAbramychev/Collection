# Реализация индивидуальных стен для каждого пользователя

## Обзор изменений

Реализована система индивидуальных стен для каждого пользователя с возможностью переключения между общей лентой и персональными стенами.

## Новые роуты

### 1. Обновленный `/wall` (общая лента)
- **Функция**: `wall()`
- **Методы**: GET, POST
- **Функциональность**:
  - Показывает посты всех пользователей
  - Поддерживает поиск по тегам (например, `#наука`)
  - Форма создания постов доступна только здесь
  - Переменная `is_global_wall=True`

### 2. Новый `/user/<username>` (индивидуальная стена)
- **Функция**: `user_wall(username)`
- **Методы**: GET
- **Функциональность**:
  - Показывает посты только конкретного пользователя
  - Отображает профиль целевого пользователя справа
  - Форма создания постов недоступна
  - Переменная `is_global_wall=False`

## Обновления в шаблоне wall.html

### 1. Условное отображение заголовка
```html
{% if is_global_wall %}
  <h2>Общая лента</h2>
{% else %}
  <h2>Стена {{ target_user.username }}</h2>
{% endif %}
```

### 2. Условное отображение формы создания поста
```html
{% if is_global_wall %}
  <!-- Форма создания поста -->
{% endif %}
```

### 3. Условное отображение профиля
```html
{% if is_global_wall %}
  <!-- Профиль текущего пользователя -->
{% else %}
  <!-- Профиль целевого пользователя -->
{% endif %}
```

### 4. Ссылки на профили пользователей
- Карточки пользователей в постах теперь являются ссылками
- При клике происходит переход на индивидуальную стену пользователя

## Функциональность

### Поиск по тегам
- Поддерживается поиск по хештегам (например, `#наука`)
- Поиск работает как на общей стене, так и на индивидуальных стенах

### Видимость профиля
- На индивидуальных стенах отображается только информация, которую пользователь разрешил показывать
- Учитываются флаги `show_*` для каждого поля профиля

### Навигация
- Легкий переход между стенами через клики по карточкам пользователей
- Сохранение контекста поиска при переходах

## Тестирование

Для тестирования функциональности:

1. Зарегистрируйтесь на сайте
2. Создайте несколько постов с тегами
3. Перейдите на `/user/<username>` для проверки индивидуальной стены
4. Проверьте поиск по тегам на обеих стенах
5. Убедитесь, что форма создания постов доступна только на общей стене
